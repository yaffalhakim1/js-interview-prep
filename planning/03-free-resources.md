- For DOM questions: paste into browser console or a plain HTML file

## Suggested workflow per question
1. Read the question. Set a 35-minute timer.
2. Solve it in Node/browser WITHOUT looking at anything.
3. Write 3–5 test cases including edge cases (empty input, cycles, `this`).
4. Compare with the repo solution; note what you missed in `progress.md`.
5. 3 days later, re-solve it from memory in <15 minutes.
